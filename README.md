## 🇲🇽 Himnario El Buen Pastor (Español)

[![React Native](https://img.shields.io/badge/React_Native-Expo_v52-blue?logo=react)](https://reactnative.dev/)
[![TypeScript](https://img.shields.io/badge/TypeScript-5.3-blue?logo=typescript)](https://www.typescriptlang.org/)

Aplicación móvil oficial de **Himnario El Buen Pastor** para iOS y Android. Diseñada para ofrecer una experiencia fluida e intuitiva de lectura y reproducción de audio de himnos y alabanzas cristianas.

### 🌟 Características Principales
* 📖 **Biblioteca de Himnos y Alabanzas:** Colección completa de himnos clasificados por número, categoría y título.
* 🎧 **Reproducción de Audio en Segundo Plano:** Escucha las alabanzas mientras navegas por la app o con la pantalla bloqueada.
* ❤️ **Favoritos y Listas Personalizadas:** Guarda tus himnos preferidos y crea listas para servicios o devocionales.
* 🔍 **Búsqueda Avanzada:** Encuentra alabanzas rápidamente por número, título o palabras clave.
* 🌐 **Soporte Multi-Idioma:** Cambia de idioma o dialecto sin perder tus configuraciones.

### 🚀 Instalación y Desarrollo Local
```bash
git clone https://github.com/lsaacd/EBP-APP.git
cd EBP-APP/himnario
npm install
npx expo start
```

## 🇺🇸 Himnario El Buen Pastor (English)

Official mobile application for **Himnario El Buen Pastor** available on iOS and Android. Designed to deliver a smooth and intuitive experience for reading lyrics and listening to Christian hymns and worship songs.

### 🌟 Key Features
* 📖 **Hymn & Praise Library:** Complete collection of hymns categorized by number, title, and topic.
* 🎧 **Background Audio Playback:** Listen to worship audio seamlessly while navigating the app or when your screen is locked.
* ❤️ **Favorites & Custom Playlists:** Save your favorite hymns and organize playlists for church services or personal devotions.
* 🔍 **Advanced Search:** Find hymns quickly by hymn number, title, or lyrics.
* 🌐 **Multi-Language Support:** Switch languages without losing your saved settings.

### 🚀 Quick Start & Local Setup
```bash
git clone https://github.com/lsaacd/EBP-APP.git
cd EBP-APP/himnario
npm install
npx expo start
```
